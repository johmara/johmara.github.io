Research Agenda

My research explores how LLM agents, guided by lightweight embedded feature annotations and distributed feature models, can turn existing features in large microservice codebases into runtime-configurable variation points, raising the level at which organizations manage variant-rich software from the code level to the feature level. The work builds on tooling for recording where features live in code and modeling them across many independently owned repositories, and is validated through a longitudinal case study on an industrial logistics platform running more than one hundred microservices. The research is conducted in collaboration with Centiro.
